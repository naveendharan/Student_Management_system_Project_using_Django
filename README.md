# Student Management System

## Project Overview

The Student Management System is a web-based application developed using Python, Django, and MySQL to manage student records efficiently. It provides a centralized platform to store, retrieve, update, and delete student information through a user-friendly administrative interface.

## Features

- **Student Registration** — Add and maintain student details.
- **Student Record Management** — View, edit, and delete student records.
- **Department Management** — Organize students by department.
- **Course Management** — Maintain student degree and course details.
- **Data Validation** — Validate student information before saving.
- **Database Integration** — Store and retrieve records using MySQL.
- **Admin Dashboard** — Manage student information through a structured interface.
- **User-Friendly Interface** — Simple and professional design using HTML, CSS, and JavaScript.

## Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/Student-Management-System.git
cd Student-Management-System
```

### 2. Create a Virtual Environment

```bash
python -m venv venv
```

Activate the environment in Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure MySQL

Create the database in MySQL:

```sql
CREATE DATABASE student_management;
```

Configure the database credentials in your Django settings or environment variables.

### 5. Apply Migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

### 6. Run the Application

```bash
python manage.py runserver
```

Open the application at:

http://127.0.0.1:8000/
